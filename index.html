UEBAKO(上羽子)

UEBAKOは、親しみやすく印象に残ることと、きちんと使いやすいことを大切にしたWebデザインを制作しています。
情報の伝わりやすさや操作のしやすさを意識しながら、イラストや手書きの要素を取り入れた、少し遊び心のあるデザインが得意です。
サイトを見る人の気持ちや、動線を考えながら、丁寧にデザインしています。

2025.11

（架空作品）

概要

　京都市・鴨川デルタで開催される架空の動物ふれあいフェスを想定し、イベントの魅力を伝えるWebサイトを制作しました。

制作情報

作成期間：1.5ヶ月

使用ツール：Figma / Procreate

使用技術：HTML / CSS

コンセプト

　大人から子どもまで幅広い世代が楽しめる動物ふれあいフェスを想定し、必要な情報を分かりやすくまとめるとともに、子どもも見て楽しめる親しみやすいデザインを目指しました。

サイトの狙い

　イベントの魅力を伝え、チケットの購入につなげることを目的として制作しました。 また、大人も子どもも楽しめるイベントであることが伝わるよう、明るく楽しい雰囲気のデザインを意識しました。 さらに、子どもでも読みやすいよう、主要な見出しはひらがな表記にし、できるだけ簡単な言葉を使用しています。

工夫したポイント

  • ワクワク感を演出するため、ポップで親しみやすいイラストを制作し、イラストをクリックすると該当する説明へ移動できるようにしました。
  • メニューバーとチケットページへの導線を常に表示し、チケット購入につながりやすい構成にしました。
  • スマートフォン・タブレット・PCそれぞれで見やすいレイアウトになるよう、レスポンシブ対応を行いました。
  • 子どもから大人まで直感的に操作できるよう、デザインだけでなく使いやすさも意識して制作しました。
作品ページ：「鴨川デルタどうぶつ日和」

2026.06

FLRM ロゴコンペ 提案作品

概要

FLRMの企業理念をもとに、理念や企業の印象を視覚的に表現するロゴを制作しました。 一つの方向性に絞るのではなく、モノグラム・折り紙・立体的な箱という異なるモチーフから3案を展開。 シンプルな形状の中に意味を持たせ、長く使用できるロゴを意識してデザインしました。

制作情報

制作内容：ロゴデザイン

使用ツール：Figma / Procreate

作成時期：2026.06

コンセプト

企業理念という目に見えないものを、 シンプルな線と形の組み合わせによって、ひとつの印象的なシンボルへ落とし込むことを意識しました。 全3案で共通して濃紺をベースに使用し、アクセントとしてオレンジを配置。 落ち着きや信頼感の中に、前向きさや動きを感じられるデザインを目指しました。 また、細かな装飾を加えるのではなく、 線や余白そのものをデザインとして扱うことで、サイズを小さくしても認識しやすいロゴを意識しています。
